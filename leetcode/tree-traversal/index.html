Binary tree traversal without recursion

Recursive tree traversal is three lines. The iterative versions matter because recursion depth equals tree height, and a degenerate tree of \(10^5\) nodes overflows Python's default recursion limit. They also make the order of visits explicit, which is what most tree problems are really about.

The examples share a small helper that builds a tree from LeetCode's level-order notation.

from collections import deque, defaultdict


class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val, self.left, self.right = val, left, right


def build(values):                              # LeetCode level order, None for a gap
    if not values or values[0] is None:
        return None
    root = TreeNode(values[0])
    q, i = deque([root]), 1
    while q and i < len(values):
        node = q.popleft()
        for side in ("left", "right"):
            if i < len(values) and values[i] is not None:
                setattr(node, side, TreeNode(values[i]))
                q.append(getattr(node, side))
            i += 1
    return root


tree = build([1, 2, 3, 4, 5, None, 6])          #       1
                                                #     2   3
                                                #    4 5    6

Preorder: root, left, right

Pop a node, visit it, push its right child then its left child, so the left is popped first.

def preorder(root):
    out, stack = [], [root] if root else []
    while stack:
        node = stack.pop()
        out.append(node.val)
        if node.right:
            stack.append(node.right)
        if node.left:
            stack.append(node.left)
    return out


assert preorder(tree) == [1, 2, 4, 5, 3, 6]

Inorder: left, root, right

Walk left as far as possible, pushing every node on the way. When you cannot go further, pop: that node's left subtree is done, so visit it and continue from its right child.

def inorder(root):
    out, stack, node = [], [], root
    while node or stack:
        while node:                             # descend left, remembering the path
            stack.append(node)
            node = node.left
        node = stack.pop()
        out.append(node.val)
        node = node.right
    return out


assert inorder(tree) == [4, 2, 5, 1, 3, 6]

Postorder, and one template for all three

Postorder is hardest because a node is visited after both children. The cleanest general fix is to push each node twice: once to expand it, once flagged as ready to visit. Changing the push order gives any of the three orders.

def traverse(root, order):
    out, stack = [], [(root, False)]
    while stack:
        node, ready = stack.pop()
        if not node:
            continue
        if ready:
            out.append(node.val)
            continue
        steps = {"pre": [(node.right, False), (node.left, False), (node, True)],
                 "in": [(node.right, False), (node, True), (node.left, False)],
                 "post": [(node, True), (node.right, False), (node.left, False)]}[order]
        stack.extend(steps)                     # pushed in reverse of the visit order
    return out


assert traverse(tree, "pre") == preorder(tree)
assert traverse(tree, "in") == inorder(tree)
assert traverse(tree, "post") == [4, 5, 2, 6, 3, 1]

Morris inorder in O(1) space

The stack versions use \(O(h)\) memory. Morris traversal uses none, by temporarily threading the tree: before descending into a left subtree, point its rightmost node back at the current node, so you can return without a stack. When you arrive back through the thread, remove it.

def morris_inorder(root):
    out, node = [], root
    while node:
        if not node.left:
            out.append(node.val)
            node = node.right
            continue
        pred = node.left                        # rightmost node of the left subtree
        while pred.right and pred.right is not node:
            pred = pred.right
        if pred.right is None:                  # first visit: thread back and go left
            pred.right = node
            node = node.left
        else:                                   # returned via the thread: unthread, visit, go right
            pred.right = None
            out.append(node.val)
            node = node.right
    return out


assert morris_inorder(tree) == inorder(tree)
assert preorder(tree) == [1, 2, 4, 5, 3, 6]     # the tree is restored afterwards

Each edge is walked at most a constant number of times, so it is still \(O(n)\).

Applications

Validate a binary search tree (98): an inorder traversal of a BST is strictly increasing, so check each value against the previous one.

def is_valid_bst(root):
    prev, stack, node = None, [], root
    while node or stack:
        while node:
            stack.append(node)
            node = node.left
        node = stack.pop()
        if prev is not None and node.val <= prev:
            return False
        prev, node = node.val, node.right
    return True


assert is_valid_bst(build([2, 1, 3]))
assert not is_valid_bst(build([5, 1, 4, None, None, 3, 6]))

Vertical order (987): give each node a (row, column), with children at column ±1. Collect by column, then sort each column by row and value, as the problem requires for ties.

def vertical_traversal(root):
    columns, q = defaultdict(list), deque([(root, 0, 0)])
    while q:
        node, row, col = q.popleft()
        if node:
            columns[col].append((row, node.val))
            q.append((node.left, row + 1, col - 1))
            q.append((node.right, row + 1, col + 1))
    return [[v for _, v in sorted(columns[c])] for c in sorted(columns)]


assert vertical_traversal(build([3, 9, 20, None, None, 15, 7])) == [[9], [3, 15], [20], [7]]
assert vertical_traversal(build([1, 2, 3, 4, 6, 5, 7])) == [[4], [2], [1, 5, 6], [3], [7]]
