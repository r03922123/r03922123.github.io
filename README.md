# r03922123.github.io

Personal hub: a list of long-form posts. Plain static HTML, served by GitHub Pages from `main`.

Each post lives in, and is deployed by, its own project repo (served at `r03922123.github.io/<repo>/`),
so its tests gate its deploy. To add a post, add one `<a class="post">` entry to `index.html`.
Do not create a top-level folder with the same name as a project repo; it would shadow that project's site.
